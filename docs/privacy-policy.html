AI Token Guard 隐私政策

最后更新：2026 年 6 月 4 日

AI Token Guard 是一个浏览器扩展，用于在支持的 AI 对话网站上进行本地 Token 统计和上下文占用估算。我们重视用户隐私，并尽量减少数据访问范围。

我们不收集个人数据

AI Token Guard 不收集、出售、共享或上传任何个人数据。扩展不会收集姓名、 邮箱、账号信息、支付信息、健康信息、位置、浏览历史或其他身份信息。

本地 Token 统计

扩展会在支持的 AI 对话网站中读取页面上可见的对话文本，用于在用户浏览器本地 估算 Token 使用量。Token 统计数据、阈值设置和浮动窗口位置仅通过 chrome.storage.local 保存在用户本地浏览器中。

不会上传对话内容

扩展不会将用户提示词、AI 回复内容、网页内容、浏览历史或 Token 统计数据发送到 任何外部服务器。

不使用远程代码

所有 JavaScript 和 WebAssembly 文件都随扩展一起打包。分词器 WebAssembly 文件 通过 chrome.runtime.getURL 从扩展包内部加载，扩展不会加载或执行 远程托管代码。

权限用途

  • storage：用于在本地保存 Token 统计、阈值设置和浮动窗口位置。
  • notifications：用于在 Token 使用量达到用户设置的阈值时显示本地提醒。
  • offscreen：用于在 Manifest V3 环境下运行本地分词器 WebAssembly。
  • 主机权限：用于仅在支持的 AI 对话网站中注入 Token 计数浮层。
